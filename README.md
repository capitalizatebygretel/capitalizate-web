# Capitalízate by Gretel García — sitio web

Sitio de **Capitalízate by Gretel García**, consultoría empresarial en Cancún y Riviera Maya.

- `index.html` — página principal (una sola página con secciones).
- `aviso-de-privacidad.html` — aviso de privacidad integral (borrador pendiente de revisión legal).
- `assets/` — logotipo, favicon e imagen para redes.

Sitio estático publicado con GitHub Pages. El dominio `capitalizatebygretel.com` se conecta desde los DNS de Squarespace.
